# Fluxo — Gestão Financeira

O **Fluxo** é um projeto de portfólio que simula um software de gestão financeira para pequenos negócios e profissionais autônomos.


## Objetivo
Criar uma experiência simples e intuitiva para acompanhar receitas, despesas, saldo disponível e movimentações financeiras em um único painel.

## Funcionalidades planejadas
- Dashboard com resumo financeiro
- Cadastro e acompanhamento de receitas e despesas
- Categorias e status das movimentações
- Filtros por período e tipo
- Relatórios visuais e interface responsiva

## Tecnologias
- Next.js
- React
- TypeScript
- CSS

## Status
Em desenvolvimento. A primeira versão será uma demonstração com dados fictícios. Recursos de autenticação e banco de dados poderão ser adicionados em etapas futuras.

## Executar localmente
```bash
npm install
npm run dev
``

Depois, acesse http://localhost:3000.
